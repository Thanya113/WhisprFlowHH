## ⚡ What is WisprFlow Studio?

**WisprFlow Studio** is a next-generation, voice-first developer cockpit built entirely using **Wispr Flow voice dictation**. It transforms unstructured spoken instructions into production-ready UI components, automated workflows, and syntax-highlighted code in real time.

Instead of typing repetitive boilerplate, developers speak naturally into Wispr Flow. The engine filters natural speech hesitations and filler words (*"um", "ah", "like", "you know"*), formats structured prompts, and immediately renders live interactive applications accompanied by syntax-highlighted code and automated voice macros.

## ✨ Core Features

### 1. 🎙️ Real-time Web Audio Waveform Visualizer
- **Dual Engine:** Connects to live microphone stream via **Web Audio API** (`getUserMedia`) with real-time FFT frequency bars, or smoothly falls back to harmonic synthesized sine waves.
- **Visual Feedback:** Live dB meter, active speech indicators, and glowing pulsing recording states.
- **Hotkeys:** Toggle recording instantly with `F8` or `Ctrl + Space`.

### 2. ⚡ Wispr Flow Intelligence Engine & NLP Cleaner
- **Filler Word Stripper:** Automatically detects and filters hesitations (*"um"*, *"ah"*, *"like"*, *"you know"*, *"basically"*) from raw microphone input.
- **Tone Adaptation Engine:** Switches output prompts between:
  - `Developer`: Concise, action-oriented, TypeScript-ready.
  - `Creative UI`: High-aesthetic cyberpunk styling with micro-animations.
  - `Architect`: Modular, decoupled architectures.
  - `Concise`: Direct, minimal prompt instructions.
- **Side-by-side Inspection:** Real-time visual comparison between raw spoken voice and Wispr Flow's optimized prompt.

### 3. 🎨 Live Component Sandbox & Multi-Device Canvas
- **Dynamic Renderers:**
  - *Cyberpunk Neon Pricing Table:* Interactive monthly/annual billing switch, glowing tier cards, and feature checks.
  - *Agile Voice Sprint Kanban Board:* Real-time task mover, priority badges, and voice task creator.
  - *Voice AI Analytics Hub:* Real-time WPM tracker, accuracy metric gauges, and animated SVG charts.
  - *Audio Memo Player:* Interactive soundbite visualizer, scrubber, and playback speed multiplier.
- **Viewport Switcher:** Preview across Desktop (100%), Tablet (768px), and Mobile (390px) frames.
- **Celebration Particle Engine:** One-click confetti bursts (`canvas-confetti`) upon voice-driven builds.

### 4. 💻 Code Inspector & Export Engine
- High-contrast syntax highlighting with line numbering.
- One-click **Copy to Clipboard** with visual toast feedback.
- One-click **Export / Download** as `.jsx` or `.json` (Voice Meta Spec).

### 5. 🚀 Voice Command Macro Studio
- Pre-configured voice triggers:
  - `"Flow: Dark Neonify"` → Injects glowing dark theme tokens.
  - `"Flow: Add TypeScript Types"` → Generates strict interfaces.
  - `"Flow: Generate Unit Tests"` → Creates automated Vitest / React Testing Library tests.
  - `"Flow: Add Confetti Burst"` → Injects interactive celebratory particle triggers.
  - `"Flow: Audit Accessibility"` → Validates WCAG AAA aria-labels.
- Custom macro builder allowing developers to map custom spoken trigger phrases to prompt pipelines.

### 6. 📱 Universal Cross-Device Compatibility
- **All Form Factors:** Fully responsive across mobile smartphones (360px–480px), tablets (768px–1024px), laptops, and ultra-wide desktop monitors.
- **Adaptive Canvas:** Dynamic stacking layouts, touch-friendly 44px+ hit targets, and horizontal swipe-enabled prompt pills.
- **Fluid Audio Waveforms:** HTML5 Canvas visualizer automatically scales to device viewport width without clipping.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation
```bash
# 1. Clone repository
git clone https://github.com/Thanya113/WhisprFlowHH.git
cd WhisprFlowHH

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build
```bash
npm run build
npm run preview
```
